# Kinemate

Pose capture for biomechanics labs. Film a subject on an Android phone, get the skeleton overlay video, joint angles and keypoints.

Open the hosted page in Chrome on Android. Everything runs on the phone; pose models (Google MediaPipe Pose Landmarker) download on first use.

## Hosting
This folder is a static site: `index.html` is the whole app. Served via GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
